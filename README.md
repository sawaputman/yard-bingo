# ヤードビンゴ

ゴルフ打ちっぱなしで遊ぶためのスマホ向け 3×3 ヤードビンゴアプリです。Next.js + TypeScript で作った最小構成で、データはブラウザの `localStorage` のみに保存します。

## 機能

- 最初の球のヤードを入力してビンゴカードを生成
- 1秒程度の生成中画面
- 3×3 のヤードビンゴカード
- マスのタップ確認ダイアログ
- クリア済みマスの見た目変更
- 横・縦・斜めのビンゴ判定
- ビンゴ達成モーダルと簡易紙吹雪演出
- 途中状態を `localStorage` に保存

## セットアップ

```bash
cd yard-bingo
npm install
```

## ローカル起動

PCだけで確認する場合:

```bash
npm run dev
```

同じ Wi-Fi のスマホから確認する場合:

```bash
npm run dev:host
```

または Next.js のオプションを直接渡します。

```bash
npm run dev -- -H 0.0.0.0
```

起動後、表示された Network URL、または PC のローカルIPを使ってスマホのブラウザで開きます。

例:

```text
http://192.168.1.10:3000
```

## 確認コマンド

```bash
npm run typecheck
npm run build
```

## 生成ルール

- 入力ヤードを基準にする
- 候補範囲は `基準 × 0.8` から `基準 × 1.2`
- 整数ヤードで9個をランダム生成
- 範囲が十分広い場合は目標ヤード同士を10ヤード以上離す
- 200yd未満など範囲が狭い入力では、指定範囲内に9個収めるため可能な最大間隔で生成
