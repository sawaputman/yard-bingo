# ギャンブルゴルフ

ゴルフ打ちっぱなしで遊ぶためのスマホ向け 3×3 ビンゴアプリです。Next.js + TypeScript で作った最小構成で、データはブラウザの `localStorage` のみに保存します。

## 機能

- 最初の球のヤードを入力してビンゴカードを生成
- 1秒程度の生成中画面
- 3×3 のヤードビンゴカード
- 各マスに目標ヤードとクリア範囲を表示
- マスのタップ確認ダイアログ
- クリア済みマスのタップでクリアを取り消し
- クリア済みマスの見た目変更
- 横・縦・斜めのビンゴ判定
- ビンゴ達成時の下部バナー表示
- 途中状態を `localStorage` に保存

## セットアップ

```bash
cd yard-bingo
npm install
```

## ローカル起動

PCだけで確認する場合:

```bash
npm run dev
```

同じ Wi-Fi のスマホから確認する場合:

```bash
npm run dev:host
```

または Next.js のオプションを直接渡します。

```bash
npm run dev -- -H 0.0.0.0
```

起動後、表示された Network URL、または PC のローカルIPを使ってスマホのブラウザで開きます。

例:

```text
http://192.168.1.10:3000
```

## 確認コマンド

```bash
npm run typecheck
npm run build
```

`next-env.d.ts` は Next.js が `dev` / `build` / `typecheck` 時に自動生成します。

## 生成ルール

- 入力ヤードを基準にする
- 候補範囲は `基準 × 0.7` から `基準 × 1.2`
- 例: 基準150ydなら105〜180yd
- 整数ヤードで9個を必ず生成
- 範囲が十分広い場合は目標ヤード同士を10ヤード以上離す
- 基準150ydなど範囲が足りない入力では、指定範囲内に9個収めるため可能な最大間隔で生成
- 判定は目標ヤードの±2yd以内
- 判定幅は `app/page.tsx` の `HIT_RANGE` 定数で管理
- 例: `HIT_RANGE = 2` で140ydのマスなら138〜142yd
- マスのクリアは確認ダイアログで行い、実測ヤード入力は不要
- ビンゴが揃ってもゲームは継続
- 景品は物理的な列ではなく、1回目/2回目/3回目のビンゴ達成順で表示
